# Contributing & Code Writing Guidelines

## General Principles

- Keep the code modular: each major feature or component should be in its own file or folder.
- Write clear, concise, and well-documented code.
- Add comments and docstrings where necessary.
- Update documentation (in docs/) when adding new features or making changes.

## Folder Guidelines

- **app/**: All mobile app code and assets. Add a README.md for any new submodule.
- **api/**: Backend API code and docs. Document endpoints and deployment steps.
- **db/**: Database schema and setup. Document any changes to the schema.
- **web/**: Web app code. Document structure and setup or any changes.

## How to Add Features

1. Create a new module or folder for your feature.
2. Add or update the README.md in the relevant folder.
3. Update docs/tasks.md and docs/changelog.md as needed.
4. Make sure your code is clear and tested.
